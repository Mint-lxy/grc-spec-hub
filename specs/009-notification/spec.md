# Spec 009 — 通知服务

> 状态：Draft
> PRD 来源：§7 M9（功能清单）、§8.9 US140–US150

## 1. 背景与目标

提供站内通知能力（P0 轻量版）：顶栏未读角标 + 通知列表，覆盖十三类关键业务事件，确保资产生命周期变更、订阅状态变化、安全事件等信息及时送达相关方。

## 2. 功能需求

### 2.1 通知基础设施

- **AC-1** — 顶栏铃铛未读角标 + 通知列表；通知保留 90 天，打开即置为已读。
- **AC-2** — 不提供分类筛选与跨模块深度跳转（P1 通知中心承载）。

### 2.2 十三类事件覆盖

- **AC-3** — 订阅申请已提交：通知该申请当前待办的全部审批人。
- **AC-4** — 订阅审批结果：通知申请人。
- **AC-5** — 发布准入测评完成：通知资产全体负责人。
- **AC-6** — 知识库构建完成或失败：通知触发者与知识库 Owner。
- **AC-7** — 订阅被 Owner 取消：通知被取消方（附理由）。
- **AC-8** — 资产发布新版本：通知全部订阅者（强治理变更附影响说明与迁移指引，未申报为轻量通知）。
- **AC-9** — 使用条款升版：通知存量订阅者与待审批申请人（附新版条款）。
- **AC-10** — 资产被下架：通知已通过订阅者（附原因）；待审批申请人同时告知申请已取消。
- **AC-11** — 资产重新上架：通知下架时刻的存量订阅者与待审批申请人。
- **AC-12** — 孤儿资产补员：通知新 Owner；原负责人恢复时通知全体有效负责人。
- **AC-13** — 出站调用停用与恢复：通知资产全体负责人（停用附原因）。
- **AC-14** — Health Check 连续失败：通知资产全体负责人（含失败起始时间与连续失败次数）。
- **AC-15** — 个人模型凭据调用失败已回落平台默认凭据：通知凭据持有人（附模型名与引导文案；仅鉴权/权限类失败触发）。

### 2.3 通知受众规则

- **AC-16** — 下架通知对待审批申请人合并为一条（不双发）。
- **AC-17** — Owner 取消订阅须必填理由并随通知发出。
- **AC-18** — 出站停用必填原因随通知发出。

## 3. 非目标 / 边界

- 通知中心完整版（P1：分类筛选/批量已读/跨模块跳转/通知偏好）
- 邮件/企业微信等外部通道
- 通知模板自定义

## 4. 未决问题

- [ ] 通知的去重策略（短时间内同一事件的合并）
- [ ] 高频事件（如 Health Check 连续失败）的通知抑制间隔
