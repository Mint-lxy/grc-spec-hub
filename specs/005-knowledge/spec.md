# Spec 005 — 知识管理

> 状态：Draft
> PRD 来源：§7 M4（功能清单）、§6 J4（用户旅程）、§8.4 US67–US96、§9.6/§9.7

## 1. 背景与目标

提供企业知识目录树（公共目录与我的目录）、知识库四阶段构建管线与参数治理、对外开放接口。目录与知识库角色由平台调用 Alice 接口发起创建，授权以 Alice 为唯一权威。

## 2. 功能需求

### 2.1 目录树与权限

- **AC-1** — 公共目录与我的目录两个根节点，最多五层。
- **AC-2** — 目录控制角色持有人可创建子目录（下沉分层）、重命名、删除（零知识库前提）。
- **AC-3** — 我的目录无角色概念，创建者本人直接操作。
- **AC-4** — 权限查看与申请：展示 Alice 权限 ID + 跳转入口（只读展示）。
- **AC-5** — 角色授予与回收：目录控制角色审批，单级审批，平台调 Alice 完成写入。

### 2.2 建库向导

- **AC-6** — 两步：基础信息 → 构建管线配置（含向量库实例选择：默认实例 + 本人已获授权的平台资源）。
- **AC-7** — 公共目录建库需知识库创建角色，平台调 Alice 创建三角色并授予创建者知识库 Owner。
- **AC-8** — 我的目录建库无需授权、不调 Alice、无角色概念。
- **AC-9** — 新建库为「草稿」。知识库创建后不可在既有目录间移动、不可复制。

### 2.3 四通道文档导入

- **AC-10** — 本地上传（40MB/单文件，ZIP 展开预览）+ Confluence + SharePoint/OneDrive + S3/Azure Blob。
- **AC-11** — 外部通道使用操作人个人出站凭据（密钥库），操作人只能导入其在来源系统有权阅读的内容。
- **AC-12** — 格式白名单外置灰不可选；重名时要求确认覆盖。
- **AC-13** — 执行导入需知识库 Contributor 及以上权限。

### 2.4 四阶段构建

- **AC-14** — 解析 → 切片 → 内容增强 → 向量化；一键构建或手动分阶段。
- **AC-15** — 失败时弹窗说明原因，失败文件置顶，可从失败阶段重跑。
- **AC-16** — 同一知识库任一时刻至多一条构建流水线（构建互斥）。
- **AC-17** — 全库重建期间保持「可用」并以旧索引服务。

### 2.5 知识库状态机

- **AC-18** — 三态：草稿 → 可用 → 已停用。首份文档完成向量化时自动转「可用」。
- **AC-19** — 知识库 Owner 可手动停用（对新会话生效）与重新启用。
- **AC-20** — 「可用」时删除最后一份已向量化文档自动回「草稿」；「已停用」不因文档删除改变状态。
- **AC-21** — 知识库删除：须先停用，软删除，Alice 接口清理角色。

### 2.6 文件状态机与详情

- **AC-22** — 五态：未解析 → 已解析 → 已切片 → 已增强 → 已向量化；任一阶段可失败。
- **AC-23** — 文件详情：源文件预览、Markdown 内容、切片搜索与编辑（编辑触发重新增强与向量化）。

### 2.7 构建参数

- **AC-24** — 解析器三选一、切片策略四选一、内容增强三选、向量化模型四选一、向量数据库二选一、检索重排序开关。
- **AC-25** — 库级参数为默认值（保存触发全库重建）；文档级可覆盖解析器/切片/增强。
- **AC-26** — 向量化模型与向量数据库锁定在库级（更换为 P1）。

### 2.8 开放接口

- **AC-27** — 三个接口（读元数据/检索/更新内容），PAT 认证。
- **AC-28** — 更新接口要求知识库 Owner 或 Contributor 权限。
- **AC-29** — 我的目录三接口均仅限创建者本人调用。

## 3. 非目标 / 边界

- 导入通道定时同步（P1）
- 库内重复文档识别（P1）
- 检索测试（P1）
- 更换知识库向量化模型（P1 功能入口，P0 预留架构灵活性）
- Azure Document Intelligence / Azure AI Search（P1）
- 知识库复制与既有目录间移动
