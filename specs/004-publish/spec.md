# Spec 004 — 发布链路与版本管理

> 状态：Draft
> PRD 来源（v1.2）：§7 M2-13/M5（功能清单）、§6 J2.3–J2.9/J6（用户旅程）、§8.3 US50–US66、§9.1/§9.1.1/§9.4

## 1. 背景与目标

实现资产从创建到上架的发布链路：发布准入测评（仅 Agent）、阻断开关、未发布修订与版本替换、使用条款轻发布、强治理变更申报、下架与重新上架、资产删除。单活版本，订阅不绑定版本。

## 2. 功能需求

### 2.1 发布准入测评

- **AC-1** — 仅 Agent 执行；MCP 免跑，质量门控通过即可上架。
- **AC-2** — 被测对象锁定、测评模板锁定为全局唯一的发布准入测评模板。
- **AC-3** — 三类测评（提示词注入/意图偏离/内容安全）各自有独立阈值，三类均达标才算通过。
- **AC-4** — 通过则直接上架；未通过按阻断开关处理（默认关闭）。
- **AC-5** — 详情页展示执行时间并标注快照语义。
- **AC-6** — 执行失败（基础设施原因）视同未通过，可重测。

### 2.2 版本模型与未发布修订

- **AC-7** — 任一时刻只有一个活版本对外服务，订阅不绑定版本。
- **AC-8** — 未发布修订是资产的可选数据属性（非状态机节点），「已发布」与「已下架」均可携带。
- **AC-9** — 修订载荷仅限版本类配置与使用条款；热改类不进入修订。
- **AC-10** — 修订存在期间在架版本持续对外服务。

### 2.3 发布（两种形态）

- **AC-11** — 轻发布（仅含使用条款）：条款版本递增、通知存量订阅者与待审批申请人、豁免门控与测评。
- **AC-12** — 版本发布（含版本类字段）：重跑质量门控与发布准入测评，通过后整体替换、版本号递增。
- **AC-13** — 发布时 Owner 显式申报是否为强治理变更（必填影响说明与迁移指引）。
- **AC-14** — 一切版本替换均通知全部订阅者。

### 2.4 中止发布

- **AC-15** — 发布进行中任一 Owner 或 Deputy 可中止，修订保留并通知发起人。
- **AC-16** — 发布进行中阻断下架与删除，提示先中止发布。

### 2.5 下架

- **AC-17** — 弹窗二次确认并必填下架原因。
- **AC-18** — 全部已通过订阅失效、待审批申请自动取消、审批人待办清除。
- **AC-19** — 运行时即时感知：调用失败返回「该资产已被下架」；入口置灰。
- **AC-20** — 下架不触碰未发布修订。

### 2.6 重新上架

- **AC-21** — 已下架可编辑修订修复问题，发布即重新上架（版本号递增、重走门控与测评）。
- **AC-22** — 重新上架不恢复订阅；不单独发送重新上架通知，由发布流程的资产发布通知覆盖（通知下架时刻的存量订阅者与待审批申请人）。
- **AC-23** — 发布语义按完成时刻资产状态判定。

### 2.7 资产删除

- **AC-24** — 未发布三态与「已下架」可删除；「已发布」须先下架。
- **AC-25** — 软删除终态：对全部用户不可见，业务记录仍永久保留。
- **AC-26** — 清理资产级服务凭据，PAT 对该资产访问失效。

### 2.8 资产生命周期状态机

- **AC-27** — 草稿 → 待发布 → 待测评 → 已发布 → 已下架 → 已删除（终态）。
- **AC-28** — 出站调用停用与资产状态正交。

## 3. 非目标 / 边界

- 多版本共存托管
- 平台对资产的持续安全检测（重测由 Owner 驱动）
- 能力声明无运行时白名单效力
- 纯条款轻发布豁免准入测评
