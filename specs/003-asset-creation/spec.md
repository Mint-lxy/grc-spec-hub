# Spec 003 — 资产创建与质量门控

> 状态：Draft
> PRD 来源（v1.2）：§7 M3（功能清单）、§6 J2（用户旅程）、§8.3 US39–US66、§9.1.1 版本模型

## 1. 背景与目标

提供自助式资产创建流程：高代码 Agent 六步向导、MCP 五步向导，按资产类型参数化的质量门控硬阻断。全员默认可创建资产，不设资格前置审批。

## 2. 功能需求

### 2.1 高代码 Agent 创建向导

- **AC-1** — 六步：基础信息 → 接入配置 → 鉴权配置 → 能力声明 → 订阅配置 → 护栏策略模板与发布说明。
- **AC-2** — 基础信息含资产负责人：创建者为首位 Owner，可增加共同 Owner 与 Deputy。
- **AC-3** — 接入配置含服务地址、Health Check 开关与一键探测、超时与重试。
- **AC-4** — 鉴权配置声明鉴权模式（静态/动态）、鉴权方式与参数名；无需声明鉴权主体类型。
- **AC-5** — 一切资产均须在此配置资产级服务凭据（资产属性，不在密钥库）并可一键探测；平台内资产调用统一使用该凭据并传递当前用户身份上下文，平台外资产调用使用平台签发的个人出站凭据。
- **AC-6** — 能力声明拉取 Agent Card，声明输入输出结构。
- **AC-7** — 订阅配置含 YAML 表单定义 + 独立必填使用条款 + 多级审批人链。
- **AC-8** — 护栏策略模板必选恰好一个启用模板。

### 2.2 MCP 创建向导

- **AC-9** — 五步：基础信息 → 链接配置 → 鉴权配置（静态凭据与动态凭据）→ 能力声明 → 订阅配置与发布说明。
- **AC-10** — 链接配置含服务地址、协议与托管方式（版本类字段）。
- **AC-11** — 能力声明拉取工具清单。

### 2.3 质量门控

- **AC-12** — Agent 七项：基础信息完整、Health Check 成功、Agent Card 合法、鉴权声明+服务凭据可用、订阅表单+使用条款已配、负责人冗余、护栏模板启用态。
- **AC-13** — MCP 六项：基础信息完整、Health Check 成功、工具清单合法、鉴权声明+服务凭据可用、订阅配置完成、负责人冗余。
- **AC-14** — 任一项未通过则阻断，修改后需重新运行。
- **AC-15** — 热改类变更与纯条款轻发布不触发门控重跑。

### 2.4 订阅配置

- **AC-16** — YAML 表单：下载模板、上传、在线编辑、实时预览。属热改类。
- **AC-17** — 使用条款：独立必填、自带版本号，变更走轻发布。
- **AC-18** — 审批人链：可视化配置并行多级，可关闭。上架后可调整，仅对新申请生效。

## 3. 非目标 / 边界

- 低代码 Agent 创建（P1，Dify 集成）
- 资产创建不设资格前置审批

## 4. 未决问题
