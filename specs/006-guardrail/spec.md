# Spec 006 — 护栏策略

> 状态：Draft
> PRD 来源（v1.2）：§7 M6（功能清单）、§6 J7（用户旅程）、§8.6 US106–US114、§9.5

## 1. 背景与目标

提供内容安全防护基线。平台管理员配置护栏策略模板（护栏组合 + 灵敏度 + 作用侧），Owner 创建 Agent 时必选一个模板，平台网关在运行时统一执行命中拦截。

## 2. 功能需求

### 2.1 模板管理

- **AC-1** — 仅平台管理员可用。模板由若干护栏组成，逐条配置灵敏度（0–100）与作用侧（输入/输出/双侧）。
- **AC-2** — 支持创建、编辑、启用、停用；违禁词表支持下载模板与上传。
- **AC-3** — 模板修改对已绑定 Agent 即时生效；停用只影响新绑定。

### 2.2 平台默认模板

- **AC-4** — 从启用模板中指定全局唯一一个，适用于 Chat 的会话。
- **AC-5** — 当前默认模板不可直接停用，须先指定另一启用模板为新默认。

### 2.3 模板绑定

- **AC-6** — Owner 创建 Agent 时从启用模板中选择恰好一个，不可不选、不可多选。
- **AC-7** — Owner 可只读查看模板条目明细（护栏/灵敏度/作用侧）。
- **AC-8** — 资产控制台可改绑其他启用模板（即时生效）。

### 2.4 绑定有效性门控

- **AC-9** — 质量门控第七项：所绑模板须处于启用状态。
- **AC-10** — 存量在架资产不受模板停用影响，仅下次门控重跑时强制校验。

### 2.5 运行时命中处置

- **AC-11** — 平台网关为唯一执行点，对一切经平台流转的对话生效。
- **AC-12** — 命中即拦截：输入侧命中直接拒答；输出侧命中以「已拦截」占位文本替代。
- **AC-13** — 输出侧检测针对完整回答：网关缓冲全文 → 检测 → 通过后按段回放 / 命中则全文不下发。
- **AC-14** — 中止生成时对已生成部分同样先检测后回放。
- **AC-15** — 响应回传命中的护栏类型。
- **AC-16** — 灵敏度 0–100，数值越高越容易命中。

### 2.6 护栏适用规则

- **AC-17** — 资产 Agent 会话适用该 Agent 绑定的模板；Chat 会话适用平台默认模板。
- **AC-18** — 任一会话恰好适用一个模板，不存在叠加。
- **AC-19** — MCP 不单独绑定护栏，其返回内容由输出侧检测覆盖。

## 3. 非目标 / 边界

- 护栏运营看板与命中记录查询（P1）
- 脱敏与告警档位（不设）
- 置信度分档（已废弃）
