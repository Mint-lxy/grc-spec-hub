# Spec 007 — 密钥库与凭据体系

> 状态：Draft
> PRD 来源（v1.2）：§7 M7（功能清单）、§6 J8（用户旅程）、§8.7 US115–US121、§9.3、ADR-0014/0016

## 1. 背景与目标

提供统一的凭据托管与解析体系。密钥库承载用户侧凭据两个管理面（入站 PAT + 出站个人凭据）。资产级服务凭据是资产属性（由 Owner 在创建向导/资产控制台维护）；平台资源凭据在管理后台平台资源注册表维护。模型类调用按触发人解析、个人优先平台默认兜底。

## 2. 功能需求

### 2.1 入站 PAT

- **AC-1** — PAT 是全部开放接口的唯一入站认证方式。
- **AC-2** — 创建时填名称、有效期（默认 90 天）、权限范围（只能勾选已授权对象的子集）。
- **AC-3** — 明文仅创建时显示一次；重新生成使原令牌立即失效。
- **AC-4** — 停用与删除需二次确认。
- **AC-5** — 持有人账号被停用时名下全部 PAT 立即失效（主体侧失效）。
- **AC-6** — 对象授权失效时该 PAT 对该对象访问失效，PAT 本身不受影响（对象侧失效）。

### 2.2 出站个人凭据

- **AC-7** — 目标类型三种：平台外资产调用、平台原生工具（知识导入通道）、Nexus 模型服务。
- **AC-8** — 平台外资产调用：凭据由平台签发、绑定用户与资产（目标限已订阅资产）；未生成、失效或调用失败时不回落任何共享身份，引导申请生成；支持申请生成/停用/撤销/重新生成。
- **AC-9** — 平台原生工具：全员可选，三者鉴权方式各不相同。
- **AC-10** — Nexus 模型服务（个人模型凭据）：不按调用点划分，同一条适用全部模型调用点；可配多条（有序列表，各有启用/禁用）。
- **AC-11** — 保存后自动全量可用性检测并保存「模型可用性列表」快照；支持手动刷新。
- **AC-12** — 解析时按序取第一条「启用且快照标记可用」的凭据；无候选则使用平台默认凭据。
- **AC-13** — 鉴权/权限类失败时本次改用平台默认凭据、快照置不可用、通知本人；瞬时故障不改写快照。
- **AC-14** — 单页配置（资源选择器 + 动态认证表单）；带参跳转时选择器折叠为只读摘要。
- **AC-15** — 密文字段掩码显示可切换明文（切换留痕）；支持一键探测。

### 2.3 资产级服务凭据（资产属性）

- **AC-16** — 每资产一份，由 Owner 在创建向导鉴权配置步或资产控制台配置。
- **AC-17** — 鉴权声明属版本类配置；密钥值属热改类（即时生效、探测前置、留痕不通知）。
- **AC-18** — 质量门控检查：资产级服务凭据须已配置并探测可用（对一切资产适用）。

### 2.4 凭据解析规则

- **AC-19** — 平台内资产调用：平台以资产级服务凭据发起调用，并传递当前用户身份上下文（供资产内部处理用户级数据权限）。
- **AC-20** — 平台外资产调用：先校验持有人已订阅目标资产，再使用平台为持有人签发、绑定用户与资产的个人出站凭据；未生成、失效或失败时不回落任何共享身份。
- **AC-21** — 模型类调用：按触发人解析，个人优先、平台默认兜底。
- **AC-22** — 管理员停用出站调用后：该资产的全部凭据解析被禁用。
- **AC-23** — 每次调用记录实际凭据主体（资产级/个人/平台资源）。

### 2.5 开放接口清单

- **AC-24** — P0 四类：资产调用、读取知识库元数据、检索知识库、更新知识库内容；资产调用链路为：PAT 入站认证 → 校验持有人已订阅目标资产 → 以平台签发的个人出站凭据发起平台外资产调用。
- **AC-25** — 平台原生工具不在开放接口之列（P0 不开放经 PAT 调用）。

## 3. 非目标 / 边界

- 密钥库不管理资产级服务凭据（资产属性）
- 密钥库不管理平台资源凭据（管理后台）
- 经 PAT 调用平台原生工具（P0 不开放）
