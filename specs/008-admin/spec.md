# Spec 008 — 管理后台与平台治理

> 状态：Draft
> PRD 来源：§7 M8（功能清单）、§6 J5（用户旅程）、§8.8 US122–US139、ADR-0009/0016

## 1. 背景与目标

提供平台管理员的治理工具集：治理中心（资产总览/出站停用/孤儿补员）、平台原生工具维护、平台资源注册表、测评阻断开关、推荐位管理、用户视图、角色映射、公共目录冷启动、模型设置。管理员不改变任何资产的状态。

## 2. 功能需求

### 2.1 治理中心

- **AC-1** — 全平台资产表：名称/类型/状态/出站停用标记/负责人；孤儿资产显著标记。
- **AC-2** — 出站调用停用（行内动作）：按资产维度，停用必填原因；调用方收到明确提示；与资产状态正交。
- **AC-3** — 孤儿资产补员：指定新 Owner（须满足有效冗余），留痕并通知；提交时复核孤儿性。
- **AC-4** — 管理员不改变资产状态，撤下与删除一律由 Owner 执行。

### 2.2 平台原生工具维护

- **AC-5** — 维护三个原生工具（Confluence/SharePoint-OneDrive/OSS MCP）的服务地址、鉴权配置与启停用。
- **AC-6** — 不上 Marketplace、免订阅、无 Owner、不适用质量门控与准入测评。

### 2.3 平台资源注册表

- **AC-7** — 每条目为一个资源实例：资源类型、连接信息、凭据、可用范围。
- **AC-8** — P0 资源类型：Milvus 实例、PGVector 实例（另预留 Azure Document Intelligence、Azure AI Search 枚举）。
- **AC-9** — 可用范围三种：默认可用（全员）、授权可用（逐人分配，不经 Alice，即时生效留痕、不通知、回收不影响存量）、平台内部。
- **AC-10** — 每类向量数据库至少一个默认实例恒存在。
- **AC-11** — 平台内部条目：Nexus 令牌、原生工具内置统一凭据。
- **AC-12** — 实例类支持连接与凭据一键探测。

### 2.4 测评阻断开关

- **AC-13** — 单一总开关，默认关闭；决定测评未通过时是否阻断上架。

### 2.5 推荐位管理

- **AC-14** — 人工置顶推荐频道资产及排序。被下架自动退出，重新上架不自动恢复。

### 2.6 用户视图与角色映射

- **AC-15** — 从 Alice 同步的用户只读列表（账号/角色/状态）。
- **AC-16** — 配置 Alice 角色到功能点与可用模型的映射；未配置的角色享有基线权限。

### 2.7 公共目录冷启动

- **AC-17** — 创建一级目录，指定一级目录控制角色与知识库创建角色持有人。

### 2.8 模型设置

- **AC-18** — 模型清单：新增/编辑/删除/启停用/设置默认模型；四类（对话/多模态/重排序/向量化）。
- **AC-19** — 每个模型条目可配置平台默认凭据（默认为 Nexus 统一令牌）。
- **AC-20** — 删除前校验在用引用（知识库/角色映射/默认模型/测评裁判），有引用则阻断。

## 3. 非目标 / 边界

- 管理员首页概览（P1）
- 系统公告（P1）
- Dify 实例管理（P1）
- 管理员不可改变资产状态、不可代下架
