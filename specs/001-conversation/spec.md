# Spec 001 — 对话工作台

> 状态：Draft
> PRD 来源（v1.2）：§7 M1（功能清单）、§6 J1.5–J1.6（用户旅程）、§8.1 US1–US20

## 1. 背景与目标

提供统一的对话入口。默认对话对象是平台 Chat agent-runtime（界面展示名 Chat）——平台自有的知识问答智能体，P0 能力仅模型对话与知识库检索（带引用证据与图片/插图）；P0 不调用平台原生工具（平台原生 MCP），也不调用已上架资产。用户订阅资产 Agent 后可经详情页「去使用」或对话工作台的资产 Agent 选择器进入透传会话（不可挂载知识库）。P1 预留 Chat 调用已订阅 MCP 资产工具的能力，但不进入 P0 对话工作台闭环。一切经平台流转的对话统一经过平台网关的护栏检测。

## 2. 功能需求

### 2.1 平台 Chat agent-runtime（Chat）

- **AC-1** — 不选择资产时对话对象为 Chat；不是资产，不上架、不可订阅、无 Owner、恒可用。
- **AC-2** — Chat 的 P0 能力有且仅有两项：模型对话、挂载知识库检索。P0 不调用平台原生工具（平台原生 MCP），不调用资产 Agent 或 MCP 资产；`tool_call` SSE 事件与消息模型中的 `toolCalls` 字段仅作既有契约兼容，并为 P1 Chat 调用已订阅 MCP 资产工具能力预留，不构成 P0 Chat 功能承诺。
- **AC-3** — 绑定平台默认护栏策略模板；用户可为 Chat 选择对话模型（仅对话类与多模态类）。
- **AC-4** — 提示词与实现随平台部署定义，P0 不提供配置入口。

### 2.2 知识库挂载与检索

- **AC-5** — 仅 Chat 会话可挂载知识库；资产 Agent 会话为透传会话，不可挂载。
- **AC-6** — 可选范围：状态为「可用」且用户持有知识库 Consumer 及以上权限的知识库 + 我的目录下状态为「可用」的知识库（含本人创建与获得可查看/可编辑分享授权的）。
- **AC-7** — 按目录树浏览、按名称搜索、按知识库多选、按文档单选。
- **AC-8** — 回答末尾展示引用来源标签；展开可见命中切片的排序位次、相似度、所属知识库与来源文档，可打开原文。
- **AC-9** — 命中的图片/插图/图表类证据在回答中内嵌渲染并标注来源文档。
- **AC-10** — 知识库检索不设会话级快照：检索行为由检索时刻的知识库状态与权限决定——库被停用或软删除后立即不可检索、回「草稿」后无可检索内容、权限被回收后检索即被拒绝；进行中的会话与新会话一视同仁。既有契约中的 `snapshotAt` 字段仅作兼容保留，不作为检索授权、知识库状态或可检索范围的判断依据；P0 可返回空值或挂载记录时间。

### 2.3 资产 Agent 透传会话

- **AC-11** — 经资产详情页「去使用」或对话工作台的资产 Agent 选择器进入，平台网关代理透传（护栏、凭据解析、审计在网关执行）。
- **AC-12** — Chat 不在场、不可挂载知识库；页面顶部展示当前对话的资产名称。
- **AC-13** — 透传会话为平台内资产调用：平台以资产级服务凭据发起调用，并传递当前用户身份上下文（供资产内部处理用户级数据权限）；订阅者无需配置个人出站凭据。

### 2.4 流式输出与护栏

- **AC-14** — 回答全文先经输出侧护栏检测，通过后按段回放；命中则全文不下发。
- **AC-15** — 中止生成时对已生成部分同样先检测后回放；命中则以「已拦截」占位文本替代。
- **AC-16** — 护栏命中时页面展示命中的护栏类型与处置结果。

### 2.5 对话基础能力

- **AC-17** — 模型选择：下拉列表仅展示对话类与多模态类模型。
- **AC-18** — 深度分析开关：开启后模型执行更多推理步骤，思考过程默认展开。
- **AC-19** — 思考过程展示：可折叠的有序步骤列表。
- **AC-20** — 回答操作：复制全文、重新生成。
- **AC-21** — 免责声明：输入区下方常驻 AI 生成提示 + 平台级用户协议链接。

### 2.6 历史会话与资产抽屉

- **AC-22** — 会话服务端持久化 90 天（自最后一条消息起算），进入集中存储前需脱敏或遮蔽敏感字段；支持搜索、按 Agent 筛选、打开恢复、删除、新建。
- **AC-23** — 已下架资产的会话可打开只读回看；发送新消息被拒。
- **AC-24** — 「我的资产」抽屉分已订阅与收藏两区；Agent 点击进对话页，MCP/未订阅进详情页。
- **AC-25** — 已下架资产条目置灰不可进入对话。

### 2.7 资产不可用提示

- **AC-26** — 三类文案：已下架、出站调用被停用、服务暂时不可用（附资产名称与负责人）。

## 3. 非目标 / 边界

- 临时文件上传（P1）
- 建议追问（P1）
- 对话记忆（P1）
- 引用阅读面板（P1）
- P0 中 MCP 资产不是对话对象，对话工作台内不可调用 MCP 资产；P1 预留 Chat 调用已订阅 MCP 资产工具的能力
- P0 中平台原生工具（平台原生 MCP）仅作知识库外部导入通道，不属于平台 Chat 对话能力，也不属于 P1 MCP 资产调用预留范围（导入语义见 spec 005，维护语义见 spec 008）
