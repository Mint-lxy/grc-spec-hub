# Spec 001 — 对话工作台

> 状态：Draft
> PRD 来源（v1.2）：§7 M1（功能清单）、§6 J1.5–J1.6（用户旅程）、§8.1 US1–US20

## 1. 背景与目标

提供统一的对话入口。默认对话对象是平台 Chat agent-runtime（界面展示名 Chat）——平台自有的知识问答智能体，能力仅模型对话与知识库检索（带引用证据与图片/插图）；不调用平台原生工具，也不调用任何资产。用户订阅资产 Agent 后可经详情页「去使用」或对话工作台的资产 Agent 选择器进入透传会话（不可挂载知识库）。一切经平台流转的对话统一经过平台网关的护栏检测。

## 2. 功能需求

### 2.1 平台 Chat agent-runtime（Chat）

- **AC-1** — 不选择资产时对话对象为 Chat；不是资产，不上架、不可订阅、无 Owner、恒可用。
- **AC-2** — Chat 能力有且仅有两项：模型对话、挂载知识库检索。不调用平台原生工具，不以任何形式调用资产 Agent 或资产 MCP。
- **AC-3** — 绑定平台默认护栏策略模板；用户可为 Chat 选择对话模型（仅对话类与多模态类）。
- **AC-4** — 提示词与实现随平台部署定义，P0 不提供配置入口。

### 2.2 知识库挂载与检索

- **AC-5** — 仅 Chat 会话可挂载知识库；资产 Agent 会话为透传会话，不可挂载。
- **AC-6** — 可选范围：状态为「可用」且用户持有知识库 Consumer 及以上权限的知识库 + 我的目录下状态为「可用」的知识库（含本人创建与获得可查看/可编辑分享授权的）。
- **AC-7** — 按目录树浏览、按名称搜索、按知识库多选、按文档单选；单会话可挂载知识库数上限 5 个（PRD §9.10 参数基线，数值待审定——2026-08-21 用户确认）。
- **AC-8** — 回答末尾展示引用来源标签；展开可见命中切片的排序位次、相似度、所属知识库与来源文档，可打开原文。
- **AC-8b** — 检索归并口径：每个挂载知识库各取相似度最高的前 5 条切片；跨库按相似度归并后取前 10 条，按来源文档去重（PRD §9.10 参数基线，数值待审定——2026-08-21 用户确认）。
- **AC-9** — 命中的图片/插图/图表类证据在回答中内嵌渲染并标注来源文档。
- **AC-10** — 知识库检索不设会话级快照：检索行为由检索时刻的知识库状态与权限决定——库被停用或软删除后立即不可检索、回「草稿」后无可检索内容、权限被回收后检索即被拒绝；进行中的会话与新会话一视同仁。

### 2.3 资产 Agent 透传会话

- **AC-11** — 经资产详情页「去使用」或对话工作台的资产 Agent 选择器进入，平台网关代理透传（护栏、凭据解析、审计在网关执行）。
- **AC-12** — Chat 不在场、不可挂载知识库；页面顶部展示当前对话的资产名称。
- **AC-12b** — 会话固定绑定唯一对话对象（Chat 或某一资产 Agent），创建时确定、不可中途变更；资产 Agent 选择器切换资产即新建/切换到该资产的会话；透传会话与 Chat 会话适用同一套持久化与管理规则（90 天、500 上限、搜索、筛选、删除，见 AC-22 系列）（旅程 J1 三.1「切换到专属透传会话」——2026-08-21 用户裁定）。
- **AC-13** — 透传会话为平台内资产调用：平台以资产级服务凭据发起调用，并传递当前用户身份上下文（供资产内部处理用户级数据权限）；订阅者无需配置个人出站凭据。
- **AC-13b** — 平台网关在每轮透传请求中携带当前消息与平台侧会话 ID；多轮对话上下文由资产自行维护，平台不向资产透传历史消息（对齐 ADR-007 A2A `contextId` 模型；避免每轮向资产全量暴露用户对话历史——2026-08-22 用户裁定）。契约影响：`grc-agent-service.yaml` 透传接口需含会话 ID 字段，随 plan/契约阶段同步。
- **AC-13c** — 透传会话不要求资产支持流式输出：平台缓冲资产完整响应，经输出侧护栏检测通过后按段回放（与 AC-14 全文缓冲检测语义自洽，用户观感与流式一致）；资产以普通请求-响应即可接入，准入门控不含流式能力校验（降低资产接入门槛——2026-08-22 用户裁定）。

### 2.4 流式输出与护栏

- **AC-14** — 回答全文先经输出侧护栏检测，通过后按段回放；命中则全文不下发。
- **AC-14b** — 输入侧护栏命中直接拦截并拒答，响应回传命中的护栏类型，页面展示命中类型与处置结果（与输出侧提示一致）；临时文件内容视同用户输入、随 P1 上传功能生效（PRD §9.5——2026-08-21 用户确认）。
- **AC-15** — 中止生成时对已生成部分同样先检测后回放；命中则以「已拦截」占位文本替代。
- **AC-15b** — 回答生成期间发送入口禁用并提示「正在生成中」；用户可经「停止生成」主动中止后立即发送；新消息不自动中止当前生成；Chat 会话与透传会话行为一致（防止同会话轮次交错破坏资产侧上下文连续性，呼应 AC-13b——2026-08-22 用户裁定）。
- **AC-16** — 护栏命中时页面展示命中的护栏类型与处置结果。

### 2.5 对话基础能力

- **AC-17** — 模型选择：下拉列表仅展示对话类与多模态类模型；仅 Chat 会话提供模型选择，资产 Agent 会话不展示模型选择器、模型由资产自身决定（PRD §7 M1-2、旅程 J1 三.1/四.2——2026-08-21 用户确认）。
- **AC-17b** — 对话主界面：无消息时展示欢迎页与输入框；有消息时展示消息流与底部固定输入区；Enter 发送、Shift+Enter 换行（PRD §7 M1-1——2026-08-21 用户确认）。
- **AC-18** — 深度分析开关：开启后模型执行更多推理步骤，思考过程默认展开；仅 Chat 会话提供，资产 Agent 会话不展示该开关（会话能力以资产返回为准，旅程 J1 三.1/四.2——2026-08-21 用户确认）。
- **AC-19** — 思考过程展示：可折叠的有序步骤列表。
- **AC-20** — 回答操作：复制全文、重新生成；重新生成按当前知识库状态重新检索并重跑模型，旧回答被直接替换、不保留历史版本（与 AC-10 无快照语义自洽——2026-08-21 用户裁定）。
- **AC-21** — 免责声明：输入区下方常驻 AI 生成提示 + 平台级用户协议链接。

### 2.6 历史会话与资产抽屉

- **AC-22** — 会话服务端持久化 90 天（自最后一条消息起算）；单用户会话数上限 500 个（PRD §9.10 参数基线，数值待审定——2026-08-21 用户确认）；支持搜索（按会话标题与首条提问，PRD §7 M1-14）、按 Agent 筛选、打开恢复、删除、新建。
- **AC-22b** — 会话数达上限时「新建会话」入口禁用并提示已达上限，引导用户删除旧会话后恢复；不自动清理任何会话（理由：会话是用户工作记录，静默清理造成无感知数据丢失；前置阻断与 002 AC-10b 风格一致——2026-08-21 用户裁定）。
- **AC-22c** — 会话标题：首轮问答完成后由模型生成摘要标题；生成失败时兜底取首条提问截断；支持手动重命名，重命名后不再被自动覆盖（2026-08-21 用户裁定）。
- **AC-22d** — 会话删除为软删除：用户侧立即不可见且不可恢复；对话原文按 PRD §9.8 继续留存至 90 天期满（自最后一条消息起算）再清除，删除不影响审计日志 3 年留存（与资产/知识库软删除终态模式一致；若 watchlist #18 合规裁定收窄为只留元数据，本条目语义不变、留存范围随动——2026-08-22 用户裁定）。
- **AC-23** — 三类失效场景下历史会话统一可打开只读回看、发送新消息被拒并按原因展示对应文案：资产已下架、订阅失效（用户退订或被 Owner 取消）、出站调用被平台停用（与 AC-26 三类提示一一对应；依据 PRD M1-14/US-14「会话内容是用户自己的数据」——2026-08-22 用户裁定）。
- **AC-24** — 「我的资产」抽屉分已订阅与收藏两区；已订阅区默认按最近使用时间倒序（无使用记录按订阅时间），收藏区默认按收藏时间倒序，两区均可切换按名称排序（PRD §7 M1-15——2026-08-21 用户确认）；Agent 点击进对话页，MCP/未订阅进详情页。
- **AC-25** — 已下架资产条目置灰不可进入对话。

### 2.7 资产不可用提示

- **AC-26** — 三类文案：已下架、出站调用被停用、服务暂时不可用（附资产名称与负责人）。
- **AC-26b** — Chat 侧生成失败（模型服务或检索服务失败、网络中断等）展示明确错误提示与重试入口；失败轮次的回答不写入会话历史，用户消息保留可直接重发（理由：失败回答无消费价值，落库会污染历史与上下文——2026-08-21 用户裁定）。

## 3. 非目标 / 边界

- 临时文件上传（P1）
- 建议追问（P1）
- 对话记忆（P1）
- 引用阅读面板（P1）
- MCP 不是对话对象，对话工作台内不可调用资产 MCP
- 平台原生工具仅作知识库外部导入通道，不属于对话能力（导入语义见 spec 005，维护语义见 spec 008）
