# 领域词汇表（Glossary）

> 防止 AI 望文生义。给出精确定义与边界，标注歧义与"不是什么"。

| 术语 | 定义 | 备注 / 不是什么 |
|------|------|-----------------|
| Spec | `specs/` 下的一个需求单元，WHAT/WHY 的事实源 | 不是设计文档（HOW 在 plan） |
| 契约 | `contracts/` 中声明的跨服务接口 | 不含服务内部接口 |
| now/ | 注入 agent 的活跃记忆当前态 | 不是历史全量，历史在 digests/archive |
| pull 模型 | 服务仓库与 hub 同级 clone，agent 沿 `../<hub>/` 直读事实源 | 服务仓库不保存 hub 内容副本 |

> 第 0 周起补充真实业务术语（订单/退款/幂等键 等）。
