# 编码标准（通用）

> 项目级标准（非组织级）。语言特定细则见 `coding-<lang>.md`。
> AI agent 生成代码必须遵守本文件。

## 通用原则
- 只做被要求或明确必要的改动；不顺手重构、不加无关"改进"。
- 不给未改动的代码补注释/文档字符串/类型标注。
- 边界处校验输入，不为不可能发生的场景加防御代码。
- 一次性操作不抽helper；避免过度工程。

## 命名与结构
- 标识符英文；语义清晰优先于简短。
- 目录/模块边界对齐服务职责，不跨契约隐式耦合。

## 安全（OWASP Top 10 基线）
- 输入校验、输出编码、参数化查询；禁止拼接 SQL。
- 不硬编码密钥；机密走密钥管理，不进代码库/日志。
- 依赖走许可证与漏洞扫描门禁。

## 错误处理
- 遵循 `architecture/cross-cutting/error-codes.md` 的统一错误体与命名空间。

## 提交
- 祈使句提交信息，关联 spec/issue。
- coding agent 的 PR 必须人审，发起人不可自批。
